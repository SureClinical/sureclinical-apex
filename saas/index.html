SureClinical SaaS Products and Services Description (SPSD)

THIS SURECLINICAL SAAS PRODUCTS AND SERVICES DESCRIPTION  (SPSD) (“Agreement”) is incorporated by reference with the Master Subscription Agreement, by and between SureClinical, Inc., a corporation organized under the laws of the State of Nevada, with a place of business at 5566 Longley Lane, Reno, NV 89511 (“SC”), and either the individual entering into this Agreement or the company on whose behalf the individual is entering into this Agreement (“Company”, “You” or “Your”) (each, a “Party” and, collectively, the “Parties”).  

List of Definitions and Terms for SureClinical’s Software as a Service (SaaS) Offerings

Application(s) – An application is a software program.  SureClinical offers cloud applications.  With cloud applications, both local and cloud-based application components work together.  For example, cloud application components are accessed through a local web browser application with a continuous internet connection.

Application Credits – Customer purchased credits applicable towards the use of the Applications, including Application Named User Credits,  Applications Project Credits, Transaction Credits, or other application credit types.

Charge Metric – measurable metrics of usage or other measurable metrics upon which charges are based.

Named User Feature Permission Set – The set of features that are assigned to a named user type:  Power Users have full feature functionality for products that they are licensed to use, Hub Users have limited feature functionality for a licensed product.  In general, hub users have mostly read-only capabilities and cannot initiate workflows for signing, web meetings or for any other workflow unless otherwise stated in the product datasheet or if explicitly offered in a license agreement or order form.

Projects are Customer projects or clinical studies with a specified project start and project stop date.  For example:  Project XYZ, starts Jan 1 2020, ends Dec 31 2020.  Project duration: 12 months.   Projects are often used to track license usage, resource usage, transaction usage and other charges.

Study Site Months (legacy metric) - Purchased credits applicable towards project / study-based Applications that use Application Credits – such as SureETMF, SureEISF, SureArchive applications.   Study site month Charge Metrics are calculated by multiplying the number of sites by the number of study months = SSM.

Site – (Legacy Metric) Study sites are organizations in a customer project and may be used as a licensing metric.  Sites can be Active, Inactive or Archived:

 Active Sites:  Active Sites are defined as site organizations and persons used in the project. Sites use SureClinical system resources such as cloud storage, workflows, digital signing transactions, web meetings, activities, tasks and reports.  

Inactive Sites:  Inactive Sites are Sites that are not being actively used in the project that don’t use SureClinical system resources.   To qualify as an inactive site, no SureClinical system resources may be associated with the Site Organization or Site Persons.  System resources include, but are not limited to:  Site documents, Site activities, Site meetings, Site workflows or Site digital signing.  For licensing purposes, if you wish to change the site status to ‘Inactive,’ all system resources must be removed, otherwise your site will be considered active.  To retain system resources for the site, change the status to ‘Archived’ as below.  Inactive sites don’t use system resources and will not be charged as an Active Site.

Archived Sites:  Archived Sites are Sites that were Active in the past, but are now Inactive and are being archived in the project, with all prior system resources retained.  To qualify as an Archived site, SureClinical system resources will be charged for cloud storage and maintenance.  New SureClinical resources cannot be allocated for Site documents, Site activities, Site meetings, Site workflows or Site digital signing, unless the site status changes to ‘Active.’  Archived sites use system resources and will be charged as an Active Site.

Site Status Changes:  Site licensing is considered a ‘named license’ for a specific site per project.  Site status changes may be made once per site every six months or by request to SureClinical support. Please contact SureClinical if you have any questions.

Client Instance - a cloud resource that contains a specific configuration of SureClinical’s SaaS Products and Services and holding Your data. 

Master Subscription Agreement or MSA  – the Master Subscription Agreement entered into by You and SureClinical which contains the applicable terms and conditions with respect to your subscriptions of SureClinical products and services, viewable online at https://sureclinical.com/msa/.   MSA's may only be renewed at the end of each Initial subscription period with the express written consent of an authorized SureClinical representative.   The start date of the MSA coincides with Your Initial Platform Subscription start date; and the the end date of the MSA coincides with Your Initial Platform Subscription end date.   Unless otherwise agreed to by both Parties in writing, all MSAs are subject to termination at the end date of Your Initial Platform Subscription.  An automatic renewal is available as a purchase option with your Initial Order Form.  

Order Form – an executed agreement to purchase SureClinical’s SaaS Products and Services, containing applicable terms and conditions with respect to a single order of SureClinical SaaS Products and Services.

Named User Licenses -  all SureClinical products accessed by any User require a named user license for each individual User.   Named User  licensing is a method of linking a software license to a specified uniquely identified individual.   For added security, Named Users may also be linked to a limited number of hardware devices in use by the Named User individual. 

 For security and compliance reasons, users may not share application credentials, and each user must have an individually-assigned application entitlement referred to as a Named User License. 

Named User Identity Verification is required for all Users.   In order to verify User Identities, SureClinical may request all of the following:  First Name, Last Name, Job Title, Organization, Organization Email Address and optionally a mobile phone for authentication of identities.  In order to issue a standard trust digital signing identity to each individual Named User, we require an Organization email address domain such as "John.Smith@MyOrg.com", where 'MyOrg.com' is used for your Organization's email address domain.  For trust and security reasons, we don't allow the use of public email services such as Gmail, Yahoo or other public email services.   All Employees, Consultants, Contingent Staff and persons who are employed by the licensing organization must have the same organization email address domain as the primary licensing organization's email address domain, unless otherwise approved by SureClinical in writing.   For high trust identity verification of Medical Doctors or others who dispense medications,  a valid government photo ID may need to be submitted by Users.  

Trusted Organization Verification:  In some cases you may wish to provide account access to SureClinical's Services to a third party organization or third party users who aren't employed by your organization.  In order to prevent potential security risks posed by third party organizations and users, You may be asked to verify the identity of third party organizations by entering the Organization Name, Organization Type (such ase Sponsor, Site, CRO, Supplier, or Partner), Organization Country and Organization email address domain into an "Organization TrustList."  We may provide a service that checks the identity of organizations that You add against our Organization BlockList.   Our BlockList contains names of Organizations who:  Have unresolved security issues with their accounts, or have been reported to SureClinical for suspected identity fraud, or who have otherwise demonstrated business practices that are considered harmful to participants in our system and network.  The Organization TrustList and BlockLists may be shared across instances for continuous organization verification, however, these lists won't be publicly published on the internet.  If you find an Organization that should not be on the BlockList, please report the Organization name and reason(s) why you believe the Organization should not be on the BlockList to our support team so that we can take appropriate action.

 Digital Certificate Issuance:  All Named Users are assigned a uniquely identifiable, non-sharable digital certificate for digital signing, identification and security. Unless otherwise offered, Named users are created once, and whether or not the user has used the products, all fees for the named user shall accrue and be payable under the order form terms. 

Named User Transfer Requests:  Named uses who are Employees, Consultants, Contingent Staff of the licensing organization and have the same email address domain as the licensing organization may transfer their named user license to a different named user upon written request to SureClinical.  Unless otherwise specified, SureClinical will consider named user transfers on the one year product subscription anniversary of the product licensed, or when Employees, Consultants, Contingent Staff in the licensing organization have left the licensing organization.  A named user is issued ONCE a unique person who is given access to SureClinical SaaS Products and Services, and a unit of measure by which the SureClinical SaaS Products and Services may be obtained, and for security and regulatory compliance, named user login credentials may not be shared. 

Transferrable Named User Subscription:  Organizations may wish to provide short term named user licenses of 3-4 months or so to several different employees or third party individuals.  For a small fee, we offer a Transferable Named User Subscription License that allows limited transfer of the Named User License to up to two individuals    The minimum term for Transferrable Named User Licenses is typically 12 months and it contains the following restrictions:  a) The initial Named User license can be reallocated to up to two different Named Users during the license subscription term; b) No individual person may receive a Transferrable Named User license twice during the  subscription license term. 

SaaS Products and Services – SureClinical’s software as a service products and services, including Applications, made available on a subscription basis. 

Subscription Agreement Term or Agreement Term – the term set forth in Your first Order Form and which shall be the term under the Master Subscription Agreement and any extensions of that term, and which shall apply to all subscriptions of SureClinical SaaS Products and Services.   All SureClinical subscription agreements are licensed on an annual basis, unless otherwise specified in the Order Form.

Products and Services Description – this Description of SureClinical’s SaaS Products and Services; additional general terms of use may be found in the Master Subscription Agreement and in the End User Subscription Agreement (click through agreement for all external users; details below).

Transaction - a unit of measure by which a specified SureClinical SaaS Product or Service feature capability is subscribed for a specified Client Instance.  For example, with SureClinical’s SureInterface Application Programming Interface (API) product, You may request that a SureClinical SaaS Product perform an ‘External data transfer’ operation, which would be charged as a Transaction.

You - client subscribing to the SureClinical SaaS Products and Services; also the ‘licensing organization.’

By executing an Order Form and purchasing SaaS Products and Services from SureClinical, You agree to this SaaS Products and Services Description.  In the event of a conflict between this SaaS Products and Services Description, and the Order Form or the Master Subscription Agreement, the documents shall prevail in the following priority:  first, the Order Form, second, the Master Subscription Agreement and third, this SaaS Products and Services Description. If You do not agree with any term or condition, do not access, open, or use the SureClinical SaaS Products or Services.

Definitions of Subscriptions, Subscription Agreement Term and Application Credits

A subscription to SureClinical SaaS Products and Services is provided with the purchase of an annual subscription.  The SaaS Products and Services that You receive as part of Your subscription depend on which SaaS Products and Services  You subscribed to, such as SureCTMS, SureQMS or other applications.  A summary of the features offered with each Product are available on SureClinical’s website under htttp://sureclinical.com/products as of the date hereof.  Additional product licensing and pricing FAQ are available on our website at https://sureclinical.com/resources/pricing/faq/.  All SC Pricing terms and conditions and licensing are subject to change. 

Platform License Requirement:  SureClinical's platform provides continuous compliance for all users, and a platform user license is required for all users who accesses our platform, whether or not they use our Applications.  Platform user licenses often include SureEsign FDA Part 11 compliant digital signing services, cloud storage, team hubs and other core digital services.  We also license our platform to each Company as the core subscription product that determines the start and end of each master subscription agreement.

Subscription Agreement Term:  The initial subscription purchase of our platform license specifies the initial Subscription Agreement Term in the Order Form.   Our minimum Subscription Agreement term for new orders is 12 months.  The Subscription Agreement Term has a subscription start date, a subscription end date and duration.  This information is specified in the Order Form. 

Mid-Term Subscription Purchases:  After the Subscription Agreement Term has commenced for initial subscription purchases,  additional subscription purchases may be made during the Subscription Agreement Term.   If a subscription purchase occurs after the initial purchase, it is considered a 'mid-term subscription purchase.'  Mid-term Subscription purchases for Services may be added during a subscription term, prorated for the portion of that subscription term remaining at the time the subscriptions are added, and any added subscriptions will co-terminate on the same date as the underlying initial Platform subscription end date.  

 The Pricing of any added subscriptions will generally be the same pricing as the underlying subscription pricing, however, we reserve the right to adjust subscription pricing for any applicable volume pricing, and for any agreed upon annual cost adjustments to our Pricing.

All Subscription User pricing is for Named Users on a monthly basis.  For mid-term subscription purchases, we may refer to our subscription unit pricing metric as "Price Per User," “Application Credit Price”, "Price Per Named User Per Month", or "Sales Price" as specified on a prior order Form.  If no Sales Price per unit is specified, the then current list price is used for subsequent application subscriptions.  

Application Credits:   Application Credits are a mechanism for Clients to control the assignment, management and usage or SureClinical SaaS Products and Services subscriptions and cloud resources.  Similar to how cell phone minutes are purchased in advance with a subscription, SureClinical Application Credits may be purchased in advance of usage under the initial or then current Subscription Agreement Term.  After Client’s purchase, the Application Credits are assigned to the Client’s Application Credit Account for the associated SureClinical Application.  Client decides how Application Credits are allocated, assigned and used through a Client application subscription settings area.

Application Credit Types:   Based on the SureClinical Application Product or Service that a Client elects to purchase a subscription for, SureClinical Application Credits are available for advance purchase.  Application Credits may be further defined by Application Credit type, such as:  Named User Credits [Named User Type], Project Credits [Project Credit Type], Transaction Credits [Transaction Type].  Named User Credits are based on how many people need to access the specified application – each user requires a subscription linked to the user's unique identity.   For Your flexibility, there are multiple Named User Types – see the table below for more details. Project Credits are created for subscribing to SureClinical Application for named projects.  Projects often have start and stop dates that don’t fall on an annual period.  Project Credits provide You with a flexible application usage model that can be controlled by You in the application subscription settings area.   Transaction Credits are designed for Application Products that are of a transactional nature, such as Application Data Exchange, Payments or Digital Signing Transaction Plans.

Digital Signing Account Types and Plans

For customers who license SureClinical’s Applications and platform, SureClinical offers two types of digital signing accounts:  Initiator Signing and Participant Signing.  ; Initiator Signing Accounts allow digital signing between a named signing initiator (‘Initiator’) and any signing process recipient (Participant).   Participant Signing Accounts allow digital signing of signing processes sent by Initiators.  Participants may not initiate signing processes.  With either signing account type, Initiators start a signing workflow process and Participants participate in the signing process. 

Unlimited Plan Option

Both Internal and External Signing Account types have an option for an Unlimited Plan license.  With this Plan, Initiators can invite multiple, unlimited numbers of Participants to participate in a signing workflow process without paying any additional signing fees.  Under the unlimited plan option, up to 200 signing workflow processes per month can be started by an Initiator for either account type. However, SureClinical may allow customers to exceed the number of signing workflow processes included in their service plan under SureClinical’s reasonable use policy: SureClinical reserves the right to prevent or stop any use of SureClinical services that appears to be abusive or is unduly burdensome.

Transaction Plan Option

 External Signing Account types have an option for a Signing Transaction Plan.  With this Plan, every signature event constitutes a single digital signing transaction. For example, if an Initiator invites a Participant to participate in a signing workflow where both the initiator and the participant sign a document, then two digital signing transaction events have occurred, and the Initiator’s account will be charged two digital signing transactions.  Under the Signing Transaction Plan, Initiators will be required to purchase digital signing transaction credits sufficient to cover all signing events in a signing transaction workflow process.  SureClinical will provide dashboards and reports of signing transaction account balances and signing transaction credit usage to users so that they can track their signing usage. SureClinical may elect to extend digital signing transaction credits, however, payment for digital signing transaction credits will be subject to SureClinical’s terms and conditions of sale.
